**Date:** 2026-09-05
**Milestone:** M30 — Comprehensive Field Test (42 open issues on GitHub)
**GitHub:** https://github.com/deghosal-2026/CauterRule/milestone/31

---

## 1. Objective

Validate the full CauterRule system end-to-end across multiple environments, failure domains, and agent types. Confirm that the extract → test → promote → inject loop measurably reduces repeat failures, that replay is deterministic and safe, and that the system is ready for production use.

The field test is the final gate before release. If the field test fails, the system is not ready for v0.1.0. If it passes, we proceed to M31 (Release Readiness) and M32 (Release).

corpus = build_tiered_corpus('corpus/public', {'tiny': 25, 'small': 100, 'medium': 1000}, seed=42)
